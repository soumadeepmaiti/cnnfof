# CNN+FoF

This repository contains the essentials of the CNN+FoF project:

- `cnn_model.py`: architecture of the CNN used in this work.
- `models/`: trained `.pth` models for the main resolutions and mass definitions tested.
- `fof_voxel/`: C++ implementation of our optimised and parallelised FoF algorithm.

This is not intended to be a fully functional, end-to-end pipeline repository. It provides the core ingredients behind the published results.

## Reference
 
CNN+FoF: application of deep learning to the identification of dark matter haloes.  
Maiti S., Correa C. M., Fiorilli A., Ruiz A. N., Paz D. J., Perez Fernández A., Sánchez A. G.
